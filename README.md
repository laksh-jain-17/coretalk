# CoreTalk 💬

> A full-stack real-time communication platform — built, deployed, and live.

🔗 **Try it now:** [coretalk.vercel.app](https://coretalk.vercel.app)

---

## What is CoreTalk?

CoreTalk is a working, deployed communication web app built entirely with the MEVN stack — MongoDB, Express.js, Vue 3, and Node.js. It's not a mockup, not a tutorial clone, and not a UI demo. It's a real application with a live backend, real-time WebSocket connections, and persistent data storage.

> ⚠️ **Note:** The backend is hosted on Render's free tier and may take up to 30 seconds to wake up on first load. Please be patient — it works once it's up.

---

## Features

- 🔐 **User Authentication** — Sign up and log in securely
- 💬 **Real-Time Chat** — Instant messaging via Socket.io
- 👥 **Group Channels** — Create and join topic-based rooms
- 📩 **Direct Messaging** — Private one-on-one conversations
- 📹 **Video & Voice Calls** — Peer-to-peer calling, in-browser

| Layer | Technology |

| Backend Hosting | Render |

---

## Why CoreTalk?

Tools like Zoom, Teams, and Google Meet are built for enterprises. CoreTalk was built to understand and demonstrate how these systems actually work — real-time socket architecture, peer-to-peer video, persistent messaging, and group channel management — all in a single full-stack MEVN codebase.

It's not competing with those tools. It's showing how they're built.
